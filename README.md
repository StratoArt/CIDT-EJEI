# Handbook Rice · CIDT EJEI 2026
Mobile-first responsive Progressive Web App (PWA) for the Rice Product Guide 2026.

## Deploy
Static website. Deploy the repository root to Vercel with Framework Preset `Other`; no build command required.

## PWA
Includes manifest, service worker, app icons, and offline caching for the app shell and local image assets. External Google Fonts require internet access.

## Update
Commit and push to the connected GitHub production branch to trigger a new Vercel deployment.
